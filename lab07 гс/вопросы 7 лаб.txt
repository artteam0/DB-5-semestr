1. Что такое последовательность (Sequence)?
Последовательность — это объект базы данных, который генерирует уникальные целые числа согласно заданным правилам.
Она не привязана к одной конкретной таблице (ее можно использовать где угодно).
Чаще всего используется для генерации первичных ключей (ID).
2. Перечислите основные параметры последовательности.
При создании (CREATE SEQUENCE) используются:
START WITH: начальное значение.
INCREMENT BY: шаг изменения (может быть положительным или отрицательным).
MINVALUE / MAXVALUE: минимальное и максимальное граничные значения.
CYCLE / NOCYCLE: нужно ли начинать сначала при достижении границы.
CACHE / NOCACHE: сколько значений заранее генерировать и хранить в оперативной памяти для быстрого доступа.
3. Какие привилегии необходимы для создания и удаления последовательности?
Для создания: CREATE SEQUENCE.
Для удаления: DROP SEQUENCE.
(Если работаете с объектами в чужой схеме, нужны права CREATE ANY SEQUENCE / DROP ANY SEQUENCE).
4. Что такое кластер?
Кластер — это объект схемы, который позволяет хранить данные из одной или нескольких таблиц физически рядом (в одних и тех же блоках данных) на диске.
Таблицы в кластере обычно связаны общими столбцами (ключом кластера).
Цель: Ускорение операций соединения (JOIN) этих таблиц, так как данные уже лежат вместе.
5. Что означает параметр hash (в кластере)?
Этот параметр указывает, что доступ к строкам данных осуществляется с помощью хэш-функции, применяемой к ключу кластера, а не через индекс.
База данных вычисляет адрес строки математически, что обеспечивает максимально быстрый доступ при поиске по точному равенству (например, WHERE ID = 100).
6. Какие привилегии необходимы для создания и удаления кластера?
Для создания: CREATE CLUSTER.
Для удаления: DROP CLUSTER.
7. Что такое синоним?
Синоним — это альтернативное имя (псевдоним) для объекта базы данных (таблицы, представления, последовательности и т.д.).
Он позволяет обращаться к объекту, не указывая имя владельца (например, просто T1 вместо XXX.T1).
Упрощает SQL-запросы и скрывает реальную структуру/владельца данных.
8. Чем отличается публичный синоним от частного синонима?
Частный (Private) синоним: Принадлежит конкретному пользователю. Доступен только ему (и тем, кому он дал права). Создается командой CREATE SYNONYM.
Публичный (Public) синоним: Принадлежит специальной группе PUBLIC. Доступен всем пользователям базы данных сразу. Создается командой CREATE PUBLIC SYNONYM.
9. Что такое материализованное представление (Materialized View)?
Это объект базы данных, который содержит результаты запроса.
В отличие от обычного представления, материализованное представление физически хранит данные (занимает место на диске) в виде таблицы-снимка.
10. Чем отличается материализованное представление от обыкновенного представления?
Обычное представление (View):
Это просто «сохраненный SQL-запрос».
Данные не хранит (виртуальная таблица).
При каждом обращении (SELECT * FROM View) запрос выполняется заново.
Данные всегда актуальны.
Материализованное представление (MV):
Хранит данные физически.
При обращении запрос не пересчитывается, данные берутся сразу с диска (это намного быстрее для тяжелых отчетов).
Данные могут устаревать. Требуется обновление (Refresh) — по расписанию или вручную, чтобы синхронизироваться с исходными таблицами.
