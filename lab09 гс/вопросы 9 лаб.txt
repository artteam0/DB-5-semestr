1. Что такое точная и неточная выборки?
Это понятия, относящиеся к оператору SELECT ... INTO в PL/SQL (неявный курсор).
Точная выборка: Запрос возвращает ровно одну строку. Это нормальное поведение для SELECT ... INTO.
Неточная выборка: Ситуация, когда запрос возвращает:
0 строк (данные не найдены) — возникает ошибка.
Более 1 строки (слишком много данных для одной переменной) — возникает ошибка.
2. Конструкции секции исключений (EXCEPTION)
WHEN NO_DATA_FOUND: Перехватывает ошибку, когда SELECT ... INTO не вернул ни одной строки (неточная выборка).
WHEN TOO_MANY_ROWS: Перехватывает ошибку, когда SELECT ... INTO вернул две и более строк, а переменная рассчитана только на одну.
WHEN OTHERS: Универсальный обработчик. Перехватывает любые ошибки, которые не были обработаны вышестоящими блоками WHEN. Обычно используется для логирования непредвиденных ошибок.
3. Назначение функций SQLERRM и SQLCODE
Эти функции используются внутри блока EXCEPTION (чаще всего в WHEN OTHERS) для диагностики:
SQLCODE: Возвращает числовой код ошибки (например, -1403 для NO_DATA_FOUND или отрицательные числа для других ошибок).
SQLERRM: Возвращает текстовое сообщение, описывающее ошибку (например, "ORA-01476: divisor is equal to zero").
4. Атрибуты курсора
Атрибуты позволяют узнать состояние курсора после выполнения команды. Они добавляются к имени курсора (для явных cur%ATTR, для неявных SQL%ATTR).
%FOUND: Возвращает TRUE, если последняя операция (FETCH или DML) успешно обработала хотя бы одну строку.
%NOTFOUND: Возвращает TRUE, если последняя операция не вернула строк (противоположность FOUND). Используется для выхода из цикла.
%ROWCOUNT: Возвращает количество строк, обработанных на данный момент (сколько удалено, обновлено или считано).
%ISOPEN: Возвращает TRUE, если курсор открыт. Для неявных курсоров (SQL%ISOPEN) всегда FALSE, так как Oracle закрывает их мгновенно после выполнения.
5. Назначение конструкции RETURNING
Используется в операторах INSERT, UPDATE, DELETE для получения значений из измененных строк без выполнения дополнительного SELECT.
Зачем нужна: Экономит ресурсы и время (одно обращение к серверу вместо двух).
Пример: DELETE FROM users WHERE id=1 RETURNING name INTO v_name; (удалили и сразу узнали, кого удалили).
6. Отличие явного и неявного курсоров
Неявный курсор (Implicit): Создается сервером автоматически для любого одиночного SQL-запроса (SELECT ... INTO) или операций DML (INSERT, UPDATE, DELETE). У него нет имени (обращаемся через SQL).
Явный курсор (Explicit): Объявляется программистом в секции DECLARE с именем (CURSOR c_name IS ...). Используется, когда запрос возвращает много строк, и их нужно обработать по одной в цикле. Программист сам управляет открытием и закрытием.
7. Схема работы с явным курсором
Стандартный алгоритм (без использования цикла FOR):
DECLARE: Объявление курсора (связывание имени с SQL-запросом).
OPEN: Открытие курсора (выполнение запроса, выделение памяти).
FETCH: Извлечение данных (читаем текущую строку в переменные). Обычно делается внутри цикла.
CLOSE: Закрытие курсора (освобождение памяти).
8. Что происходит по команде OPEN курсора?
Выделяется память под курсор (context area).
Выполняется SQL-запрос, связанный с курсором.
Формируется активный набор данных (result set).
Указатель устанавливается перед первой строкой. Данные в переменные еще не загружаются.
9. Особенность цикла FOR с явным курсором
Цикл FOR record IN cursor_name LOOP ... END LOOP; автоматизирует работу:
Сам делает OPEN.
Сам делает FETCH на каждой итерации.
Сам проверяет EXIT WHEN %NOTFOUND.
Сам делает CLOSE при завершении цикла или ошибке.
Автоматически создает переменную-запись (record) типа %ROWTYPE.
10. Параметры курсора
Для чего: Чтобы использовать один и тот же курсор для разных данных (например, найти студентов разных групп). Это делает курсор универсальным.
Где указываются: В объявлении курсора в скобках: CURSOR c1 (p_id NUMBER) IS ....
Как передаются: В команде OPEN c1(10); или в цикле FOR r IN c1(10).
11. Курсорная переменная (REF CURSOR)
Это указатель на курсор, который можно передавать между процедурами и функциями. В отличие от обычного курсора, курсорная переменная динамическая — её можно открывать для разных запросов в разное время.
Объявление:
code
SQL
TYPE t_ref IS REF CURSOR; -- Слабый тип
v_cur t_ref;              -- Переменная
-- Или использование системного типа:
v_cur SYS_REFCURSOR;
12. Курсорный подзапрос
Это когда определение курсора содержит вложенный запрос. Но чаще в контексте PL/SQL это выражение CURSOR(SELECT ...) внутри списка выборки основного запроса. Это позволяет вернуть в одной строке данные и вложенный набор данных (например, название отдела и сразу список всех его сотрудников).
13. Назначение конструкции CURRENT OF
Используется в UPDATE или DELETE внутри цикла по курсору.
Позволяет изменить или удалить именно ту строку, которую курсор обрабатывает в данный момент, без повторного поиска по WHERE id = ....
Требует: Объявления курсора с фразой FOR UPDATE.
Синтаксис: DELETE FROM table WHERE CURRENT OF cursor_name;
14. Псевдостолбец ROWID
Это физический адрес строки в базе данных.
Назначение: Самый быстрый способ доступа к строке (быстрее, чем по Primary Key).
Структура: Это 18-символьная строка (Base64), кодирующая:
Номер объекта данных.
Номер файла данных.
Номер блока в файле.
Номер строки в блоке.
15. Псевдостолбец ROWNUM
Это порядковый номер строки в возвращаемой выборке.
Назначение: Используется для ограничения количества строк (например, WHERE ROWNUM <= 5 для получения "топ-5").
Важно: Номера присваиваются до сортировки (ORDER BY), поэтому для корректных топов нужно использовать вложенный подзапрос.
