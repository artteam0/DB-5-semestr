1. Редакции поставки Oracle 12c
Oracle Database 12c поставляется в нескольких редакциях, чтобы соответствовать различным потребностям и бюджетам. Основные из них:
Enterprise Edition (EE): Наиболее полная и функциональная редакция, предназначенная для крупных предприятий с высокими требованиями к производительности, доступности и безопасности.[1][2]
Standard Edition (SE): Подходит для рабочих групп, отделов и небольших компаний.
Standard Edition One (SE1): Более доступная версия, предназначенная для малого бизнеса с ограниченными потребностями.[1]
2. Предопределенные пользователи БД Oracle
При создании базы данных Oracle автоматически создается несколько предопределенных учетных записей пользователей.[3] Наиболее важные из них:
SYS: Самый привилегированный пользователь, владеющий словарем данных. Используется для выполнения основных задач администрирования.[4]
SYSTEM: Также является высокопривилегированным пользователем, который традиционно используется для создания дополнительных административных объектов, не входящих в ядро словаря данных.
XELSYSADM, WEBLOGIC, OIMINTERNAL: Это примеры других предопределенных пользователей, которые могут создаваться в зависимости от установленных компонентов.[5]
3. Что такое табличное пространство?
Табличное пространство (tablespace) — это логическая единица хранения в базе данных Oracle, которая группирует связанные логические структуры, такие как таблицы и индексы.[6][7] Оно служит для абстрагирования от физического расположения данных, позволяя администраторам управлять хранением объектов базы данных.[6][8][9]
4. В каком соотношении находятся табличные пространства и файлы данных?
Соотношение между табличными пространствами и файлами данных следующее:
Одно табличное пространство может состоять из одного или нескольких файлов данных.[10][11]
Один файл данных может принадлежать только одному табличному пространству.[10]
Это соотношение "один ко многим".[10]
5. Известные вам параметры табличного пространства
При создании или изменении табличного пространства можно задать различные параметры, в том числе:
LOGGING / NOLOGGING: Определяет, будут ли операции записываться в журнал повторного выполнения.
AUTOEXTEND ON / OFF: Указывает, будет ли файл данных автоматически расширяться при необходимости.[7]
NEXT: Задает размер следующего экстента при автоматическом расширении.[7]
MAXSIZE: Устанавливает максимальный размер, до которого может вырасти файл данных.[7]
EXTENT MANAGEMENT: Определяет, как управляются экстенты (участки дискового пространства) — локально в табличном пространстве или централизованно в словаре данных.
6. Типы табличных пространств и их назначение
Существуют различные типы табличных пространств, каждый из которых предназначен для определенных целей:
PERMANENT (Постоянные): Для хранения постоянных объектов базы данных, таких как таблицы и индексы.[12]
TEMPORARY (Временные): Используются для хранения временных данных, например, во время операций сортировки.[12][13]
UNDO (Для отмены): Хранят информацию, необходимую для отката транзакций и обеспечения согласованности чтения данных.[12]
Также существуют обязательные системные табличные пространства:
SYSTEM: Содержит словарь данных и другую системную информацию.[13]
SYSAUX: Вспомогательное табличное пространство для компонентов и продуктов Oracle.[13]
7. Что такое роль и для чего она применяется?
Роль в Oracle — это именованная группа связанных привилегий.[14][15] Роли упрощают управление правами доступа: вместо того, чтобы предоставлять множество отдельных привилегий каждому пользователю, можно предоставить привилегии роли, а затем назначить эту роль пользователям.[14][16]
8. Какие системные роли вы знаете? Объясните их назначение
В Oracle существует ряд предопределенных системных ролей:
CONNECT: Предоставляет базовые привилегии, необходимые для подключения к базе данных.[17]
RESOURCE: Позволяет пользователю создавать объекты в своей схеме (таблицы, индексы и т.д.).[17]
DBA (Database Administrator): Предоставляет широкий спектр системных привилегий для администрирования базы данных.
PUBLIC: Специальная роль, привилегии которой автоматически доступны всем пользователям.[17]
9. Что такое системная привилегия, какие системные привилегии вы знаете?
Системная привилегия — это право на выполнение определенных действий на уровне всей базы данных.[18][19] В Oracle существует более 100 различных системных привилегий.[20] Вот некоторые из них:
CREATE SESSION: Позволяет пользователю подключаться к базе данных.[18][21]
CREATE TABLE: Позволяет пользователю создавать таблицы в своей схеме.[18][21]
CREATE ANY TABLE: Позволяет пользователю создавать таблицы в любой схеме базы данных.[20]
DROP USER: Позволяет удалять пользователей.[20]
CREATE USER: Позволяет создавать новых пользователей.[20]
10. Какие специальные системные привилегии администратора БД вы знаете? Как их назначить?
Существуют специальные привилегии для администраторов, которые позволяют выполнять критически важные операции:
SYSDBA: Наивысший уровень привилегий, позволяющий выполнять любые действия по администрированию, включая запуск и остановку базы данных.
SYSOPER: Ограниченный набор административных привилегий, достаточный для выполнения базовых операционных задач, таких как резервное копирование и восстановление.
Эти привилегии назначаются пользователю при подключении к базе данных, например: CONNECT username/password AS SYSDBA;
11. Что такое профиль безопасности и для чего он нужен?
Профиль безопасности (profile) — это именованный набор ограничений на использование ресурсов базы данных и политик паролей. Профили используются для контроля потребления ресурсов пользователями и для усиления безопасности путем применения требований к паролям.
12. Перечислите известные вам параметры профиля безопасности и поясните их
Параметры профиля безопасности делятся на две категории:
Ограничение ресурсов:
SESSIONS_PER_USER: Максимальное количество одновременных сессий для пользователя.
CPU_PER_SESSION: Максимальное процессорное время на сессию.
Управление паролями:
FAILED_LOGIN_ATTEMPTS: Количество неудачных попыток входа, после которого учетная запись блокируется.
PASSWORD_LIFE_TIME: Срок действия пароля.
PASSWORD_LOCK_TIME: Время, на которое блокируется учетная запись.
13. Объясните назначение профиля с именем DEFAULT
Профиль DEFAULT создается автоматически при создании базы данных. Если пользователю при создании не был явно назначен другой профиль, к нему применяются ограничения, установленные в профиле DEFAULT. Изначально все параметры в этом профиле установлены в UNLIMITED.
14. Что такое пользователь базы данных?
Пользователь базы данных (или схема) — это учетная запись, которая позволяет подключаться к базе данных Oracle. С каждым пользователем связана своя схема, которая является коллекцией объектов базы данных (таблиц, представлений, процедур и т.д.), принадлежащих этому пользователю.
15. Перечислите известные вам параметры пользователя БД Oracle
При создании пользователя можно указать следующие параметры:
IDENTIFIED BY [пароль]: Устанавливает пароль для аутентификации.
DEFAULT TABLESPACE: Определяет табличное пространство по умолчанию для объектов пользователя.[22]
TEMPORARY TABLESPACE: Задает временное табличное пространство для пользователя.[22]
QUOTA ... ON ...: Устанавливает квоту дискового пространства в указанном табличном пространстве.[22]
PROFILE: Назначает пользователю профиль безопасности.
16. Что такое квота?
Квота (quota) — это ограничение на объем дискового пространства, которое пользователь может использовать для хранения своих объектов в определенном табличном пространстве.[23] Это позволяет администратору контролировать распределение дисковых ресурсов.
17. Перечислите все известные вам представления словаря БД Oracle
Словарь данных (Data Dictionary) — это набор таблиц и представлений, содержащих метаданные о базе данных.[24][25][26] Доступ к этой информации осуществляется через представления словаря данных, которые сгруппированы по префиксам:
USER_*: Содержат информацию об объектах, принадлежащих текущему пользователю. (например, USER_TABLES, USER_OBJECTS).[27]
ALL_*: Показывают информацию обо всех объектах, к которым текущий пользователь имеет доступ. (например, ALL_TABLES).[27]
DBA_*: Содержат информацию обо всех объектах в базе данных. Доступ к этим представлениям обычно имеют только администраторы. (например, DBA_USERS, DBA_TABLESPACES).[27]
