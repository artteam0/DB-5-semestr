1. Поясните тезис «PL/SQL – процедурное расширение SQL»
SQL (Structured Query Language) — это декларативный язык: мы говорим «что выбрать», но не «как делать». В чистом SQL нет переменных, циклов FOR/WHILE, условных переходов IF.
PL/SQL (Procedural Language extension to SQL) добавляет эти процедурные возможности. Он позволяет писать полноценные программы с логикой, ветвлениями и обработкой ошибок, внутри которых выполняются SQL-команды.
2. Чувствителен ли к регистру язык PL/SQL?
Код: Нет. Ключевые слова (BEGIN, begin), имена переменных и объектов нечувствительны к регистру.
Строковые литералы: Да. Строка 'Hello' и 'hello' — это разные значения.
3. Что такое анонимный блок?
Это блок кода PL/SQL, который не имеет имени и не сохраняется в базе данных. Он компилируется и выполняется за один раз, передаваясь с клиента на сервер.
Почему анонимный: У него нет имени в заголовке, в отличие от процедур или функций.
Простейший блок:
code
SQL
BEGIN
   NULL;
END;
4. Вывод DBMS_OUTPUT в SQL+ и SQLDeveloper
Чтобы серверный вывод (то, что пишет DBMS_OUTPUT.PUT_LINE) отобразился у клиента:
SQL*Plus / Консоль: Выполнить команду SET SERVEROUTPUT ON.
SQL Developer: В меню View -> Dbms Output, нажать зеленый плюс и выбрать соединение.
5. Секции программы PL/SQL
Блок состоит из 3 секций (плюс заголовок для именованных блоков):
DECLARE (Необязательная): Объявление переменных, курсоров, типов.
BEGIN (Обязательная): Исполняемая часть, логика программы.
EXCEPTION (Необязательная): Обработка ошибок.
END; (Обязательная): Конец блока.
6. Что такое исключение PL/SQL?
Исключение (Exception) — это ошибка или предупреждение, возникающее во время выполнения программы (runtime error). Когда оно возникает, нормальное выполнение кода прерывается, и управление передается в секцию EXCEPTION.
7. Вложенные блоки
Это когда внутри секции BEGIN ... END одного блока находится другой блок DECLARE ... BEGIN ... END.
Для чего: Для локализации переменных (область видимости), группировки логики и, главное, для локальной обработки ошибок.
Работа исключений: Если ошибка возникает во внутреннем блоке, она ищет обработчик в его секции EXCEPTION. Если обработчика нет — ошибка "всплывает" (пропагирует) во внешний блок.
8. Совпадают ли типы данных БД Oracle и PL/SQL?
Частично.
PL/SQL поддерживает все типы данных, которые есть в таблицах (NUMBER, VARCHAR2, DATE и т.д.).
Но в PL/SQL есть дополнительные типы, которых нет в таблицах: BOOLEAN (истина/ложь), PLS_INTEGER (быстрые целые), записи (RECORD), ассоциативные массивы.
Пример: Нельзя создать таблицу с полем типа BOOLEAN.
9. Какая семантика символов используется в Oracle?
Используется BYTE или CHAR семантика.
VARCHAR2(10 BYTE) — 10 байт (для UTF-8 это может быть всего 5 русских букв).
VARCHAR2(10 CHAR) — 10 символов (независимо от их веса в байтах).
По умолчанию часто стоит BYTE, поэтому для русского языка рекомендуется явно указывать CHAR или увеличивать размер.
10. Типы данных для символьной информации
В БД: CHAR, VARCHAR2, NCHAR, NVARCHAR2, CLOB (большие тексты), LONG (устаревший).
В PL/SQL: Все перечисленные выше + подтипы (например, VARCHAR, STRING — синонимы).
11. Типы данных для числовых данных
В БД: NUMBER (универсальный), FLOAT, BINARY_FLOAT, BINARY_DOUBLE.
В PL/SQL: Все вышеперечисленные + PLS_INTEGER, BINARY_INTEGER (целочисленные типы, оптимизированные для вычислений в процессоре, работают быстрее NUMBER).
12. Операции, использованные в работе
Арифметические: +, -, *, /, ** (степень).
Присваивание: :=
Конкатенация строк: ||
Сравнение: =, != (или <>), <, >, <=, >=, IS NULL, LIKE, BETWEEN.
Логические: AND, OR, NOT.
13. Представления словаря БД, связанные с PL/SQL
USER_SOURCE (или ALL_SOURCE) — исходный код процедур/функций.
USER_ERRORS — ошибки компиляции.
USER_OBJECTS — статус объектов (VALID/INVALID).
V$RESERVED_WORDS — зарезервированные ключевые слова.
V$PARAMETER — настройки сервера.
14. Как получить параметры Oracle, связанные с PL/SQL?
SQL-запрос:
code
SQL
SELECT name, value FROM v$parameter WHERE name LIKE 'plsql%';
Команда SQL*Plus:
code
SQL
SHOW PARAMETER plsql;
